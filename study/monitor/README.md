## 快速开始

### 1. 添加监控功能

在 `task.c` 的 `start_task` 函数中添加：

```c
#include "sys_monitor.h"

void start_task(void *p_arg)
{
    OS_ERR err;
    
    /* ... 其他初始化 ... */
    
    /* 初始化系统监控 */
    SysMonitor_Init();
    
    OSTaskDel(NULL, &err);
}
```

### 2. 查看监控输出

打开串口调试助手，波特率 115200，查看监控输出。

### 3. 分析监控数据

对照 `监控数据快速参考.c` 中的判断表，分析系统状态。

### 4. 优化调整

根据 `任务分配合理性分析指南.c` 中的建议，修改任务配置。

## 关键指标速查

### CPU使用率
- < 60%：正常
- 60% - 80%：繁忙，考虑优化
- > 80%：过载，必须优化

### 堆栈使用率
- < 50%：安全
- 50% - 70%：警告
- > 70%：危险，增加堆栈

### 上下文切换
- < 5000次/秒：正常
- > 10000次/秒：过高，增加任务周期

## 常见问题

### Q: 监控任务影响系统性能吗？
A: 影响很小。监控任务优先级最低（20），每5秒执行一次。

### Q: 为什么CPU使用率显示0%？
A: 刚启动时正常，需要等待几秒钟让统计任务计算出准确值。

### Q: 堆栈使用率突然变高？
A: 可能是中断嵌套或printf使用，建议保留30%余量。

### Q: 如何判断任务死锁？
A: 如果任务长期处于Pending状态（>10秒），可能死锁。
