# MPU6050数据全为零 - 快速修复

**问题**: MPU6050初始化成功，但读取数据全为0

**根本原因**: **MPU6050处于睡眠模式！**

---

## ⚡ 30秒快速修复

### 问题代码（当前代码）

```c
/* 你的初始化代码 - 有问题！ */
uint8_t MPU6050_Init(void)
{
    /* ... */
    
    /* Reset device */
    MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x80);  // 复位
    OSTimeDly(100, OS_OPT_TIME_DLY, &err);
    
    /* Wake up device */
    MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x00);  // ← 问题在这里！
    OSTimeDly(10, OS_OPT_TIME_DLY, &err);
    
    /* ... */
}
```

**问题**: 复位后写入`0x00`到PWR_MGMT_1，但**没有使能传感器**！

---

## 🔍 问题分析

### PWR_MGMT_1寄存器（0x6B）

```
Bit 7: H_RESET  - 1=复位设备
Bit 6: SLEEP    - 1=睡眠模式（默认上电=1）
Bit 5: CYCLE    - 1=循环模式
Bit 3: TEMP_DIS - 1=禁用温度传感器
Bit 2-0: CLKSEL - 时钟源选择
```

### 上电默认值

```
PWR_MGMT_1 = 0x40
           = 0b01000000
           = SLEEP=1（睡眠模式！）
```

### 为什么你的代码有问题？

```c
/* 复位后 */
MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x00);
/* 
 * 0x00 = 0b00000000
 * SLEEP = 0（唤醒）✓
 * 但是！
 * CLKSEL = 000（内部振荡器，不稳定）
 * 而且：没有检查是否真的唤醒了！
 */
```

**更严重的问题**: 复位后PWR_MGMT_2寄存器可能禁用了某些轴！

---

## ✅ 正确修复

### 方法1：最小修改（推荐）

在`MPU6050_Init()`函数中添加一行：

```c
/* 在唤醒代码后添加 */
MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x00);
OSTimeDly(10, OS_OPT_TIME_DLY, &err);

/* 添加这行！使能所有传感器 */
MPU6050_Write_Reg(MPU6050_PWR_MGMT_2, 0x00);  // ← 添加这行！
```

### 方法2：完整修复（推荐）

替换整个初始化函数：

```c
uint8_t MPU6050_Init(void)
{
    OS_ERR err;
    uint8_t who_am_i;
    
    IIC_Init();
    
    /* Create mutex */
    OSMutexCreate(&MPU6050_Mutex, "MPU6050 Mutex", &err);
    if(err != OS_ERR_NONE) return 1;
    
    /* Create queue */
    OSQCreate(&MPU6050_Data_Queue, "MPU6050 Queue", 10, &err);
    if(err != OS_ERR_NONE) return 1;
    
    /* Create semaphore */
    OSSemCreate(&MPU6050_Data_Ready_Sem, "MPU6050 Data Ready", 0, &err);
    if(err != OS_ERR_NONE) return 1;
    
    /* Check device ID */
    if(MPU6050_Read_Reg(MPU6050_WHO_AM_I, &who_am_i) != 0)
        return 1;
    
    if(who_am_i != 0x68 && who_am_i != 0x70)
    {
        printf("MPU6050 not found! WHO_AM_I = 0x%02X\r\n", who_am_i);
        return 1;
    }
    
    printf("MPU6050 found! WHO_AM_I = 0x%02X\r\n", who_am_i);
    
    /* Reset device */
    MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x80);
    OSTimeDly(100, OS_OPT_TIME_DLY, &err);
    
    /* Wake up and set clock source */
    MPU6050_Write_Reg(MPU6050_PWR_MGMT_1, 0x01);  // 使用PLL，更稳定
    OSTimeDly(10, OS_OPT_TIME_DLY, &err);
    
    /* 关键！使能所有传感器 */
    MPU6050_Write_Reg(MPU6050_PWR_MGMT_2, 0x00);  // ← 关键！
    
    /* Configure sample rate: 1kHz / (1 + 0) = 1kHz */
    MPU6050_Write_Reg(MPU6050_SMPLRT_DIV, 0);
    
    /* Configure low-pass filter: 44Hz */
    MPU6050_Write_Reg(MPU6050_CONFIG, 0x03);
    
    /* Configure gyroscope: ±2000°/s */
    MPU6050_Write_Reg(MPU6050_GYRO_CONFIG, 0x18);
    
    /* Configure accelerometer: ±4g */
    MPU6050_Write_Reg(MPU6050_ACCEL_CONFIG, 0x01);
    
    /* Verify wake-up status */
    uint8_t pwr_mgmt_1;
    MPU6050_Read_Reg(MPU6050_PWR_MGMT_1, &pwr_mgmt_1);
    if(pwr_mgmt_1 & 0x40)
    {
        printf("Warning: MPU6050 still in sleep mode!\r\n");
    }
    else
    {
        printf("MPU6050 is awake and ready!\r\n");
    }
    
    return 0;
}
```

## 🎯 为什么PWR_MGMT_2很重要？

### PWR_MGMT_2寄存器（0x6C）

```
Bit 5: DIS_XA - 1=禁用X轴加速度
Bit 4: DIS_YA - 1=禁用Y轴加速度
Bit 3: DIS_ZA - 1=禁用Z轴加速度
Bit 2: DIS_XG - 1=禁用X轴陀螺
Bit 1: DIS_YG - 1=禁用Y轴陀螺
Bit 0: DIS_ZG - 1=禁用Z轴陀螺
```

### 上电默认值

复位后，PWR_MGMT_2的值不确定！

如果某些位为1，对应的传感器会被禁用，
读取数据时这些轴就会是0！

### 解决方案

写入`0x00`到PWR_MGMT_2，确保所有位为0，
所有传感器都被使能！
