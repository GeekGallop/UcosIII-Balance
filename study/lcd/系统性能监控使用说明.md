# uC/OS-III 系统性能监控使用说明

## 概述

本监控模块利用 uC/OS-III 内置的统计功能，提供以下性能数据：

- **CPU 使用率** - 实时和峰值 CPU 占用率
- **任务堆栈使用率** - 每个任务的堆栈使用情况
- **任务状态** - 任务当前运行状态
- **中断统计** - 中断禁用时间
- **上下文切换** - 切换次数统计
- **消息队列** - 队列使用情况

---

## 前置条件

### 1. 确保 os_cfg.h 中启用了统计任务

在 `Middlewares\uC-OS3\uC-OS3\Cfg\Template\os_cfg.h` 中：

```c
#define OS_CFG_STAT_TASK_EN             1u   /* 启用统计任务 */
#define OS_CFG_STAT_TASK_STK_CHK_EN     1u   /* 启用堆栈检查 */
#define OS_CFG_DBG_EN                   1u   /* 启用调试功能 */
#define OS_CFG_TS_EN                    1u   /* 启用时间戳功能（用于中断统计） */
```

### 2. 确保 os_cfg_app.h 中配置了统计任务

在 `Middlewares\uC-OS3\uC-OS3\Cfg\Template\os_cfg_app.h` 中：

```c
#define OS_CFG_STAT_TASK_PRIO           11u   /* 统计任务优先级 */
#define OS_CFG_STAT_TASK_RATE_HZ        10u   /* 统计任务频率 */
#define OS_CFG_STAT_TASK_STK_SIZE       128u  /* 统计任务栈大小 */
```

### 2. 确保 os_cfg_app.h 中配置了统计任务栈大小

```c
#define OS_CFG_STAT_TASK_STK_SIZE       128u /* 统计任务栈大小 */
```

### 3. 在 main.c 中启动统计任务

```c
#include "os.h"

int main(void)
{
    OS_ERR err;
    
    OSInit(&err);
    
    /* 其他初始化... */
    
    /* 启动统计任务（在 OSStart 之前） */
    OSStatTaskCPUUsageInit(&err);
    
    OSStart(&err);
    
    return 0;
}
```

**注意**: `OSStatTaskCPUUsageInit()` 必须在 `OSStart()` 之前调用，用于初始化 CPU 使用率计算。

## 使用方法

### 方法一：自动监控（推荐）

在系统启动后初始化监控任务：

```c
#include "sys_monitor.h"

void start_task(void *p_arg)
{
    OS_ERR err;
    
    /* ... 其他初始化 ... */
    
    /* 初始化系统监控（会创建一个低优先级任务自动打印统计信息） */
    if(SysMonitor_Init() != 0) {
        printf("Failed to init system monitor!\r\n");
    }
    
    /* 删除启动任务 */
    OSTaskDel(NULL, &err);
}
```

### 方法二：手动查询

在任意任务中手动查询特定信息：

```c
#include "sys_monitor.h"

void SomeTask(void *p_arg)
{
    OS_ERR err;
    CPU_INT16U cpu_usage;
    CPU_STK_SIZE free_stk, used_stk;
    
    while(1)
    {
        /* 获取 CPU 使用率 */
        cpu_usage = SysMonitor_GetCPUUsage();
        printf("Current CPU Usage: %d.%02d%%\r\n", 
               cpu_usage / 100, cpu_usage % 100);
        
        /* 获取特定任务的堆栈使用情况 */
        if(SysMonitor_GetTaskStackUsage(&Protocol_Task_TCB, 
                                        &free_stk, &used_stk) == 0) {
            printf("Protocol Task Stack: %d used, %d free\r\n",
                   (int)used_stk, (int)free_stk);
        }
        
        /* 打印特定任务信息 */
        SysMonitor_PrintTaskInfo(&LCD_Task_TCB, "LCD_Task");
        
        OSTimeDly(1000, OS_OPT_TIME_DLY, &err);
    }
}
```

### 方法三：在调试时临时使用

可以在命令处理或调试任务中临时调用：

```c
void Debug_CommandHandler(char *cmd)
{
    if(strcmp(cmd, "status") == 0) {
        /* 打印所有任务状态 */
        OS_TCB *p_tcb = OSTaskListPtr;
        while(p_tcb != NULL) {
            SysMonitor_PrintTaskInfo(p_tcb, NULL);
            p_tcb = p_tcb->NextPtr;
        }
    }
    else if(strcmp(cmd, "cpu") == 0) {
        /* 打印 CPU 使用率 */
        CPU_INT16U usage = SysMonitor_GetCPUUsage();
        printf("CPU: %d.%02d%%\r\n", usage / 100, usage % 100);
    }
}
```

## 关键指标说明

### CPU 使用率

- **Current**: 当前 CPU 使用率
- **Peak**: 历史最高 CPU 使用率
- **Idle**: 空闲任务占用率（越高表示系统越空闲）

**注意**: CPU 使用率计算需要统计任务运行一段时间（通常几秒钟）后才会准确。

### 堆栈使用率

格式：`已使用/总大小(百分比)`

- 堆栈使用率超过 **80%** 需要警惕
- 堆栈使用率超过 **90%** 非常危险，需要增加栈大小
- 建议保持堆栈使用率在 **50%** 以下

### 任务状态

| 状态 | 说明 |
|------|------|
| Ready | 就绪，等待 CPU |
| Delayed | 延时等待中 |
| Pending | 等待信号量/互斥锁/消息队列 |
| PendDly | 等待资源同时超时等待 |
| Suspend | 被挂起 |

### 中断禁用时间

- 表示系统关闭中断的最长时间
- 数值越小越好，通常应该小于 100 微秒
- 过长会影响实时性

### 上下文切换

- 表示任务切换的总次数
- 切换次数/秒可以反映系统繁忙程度

## 配置选项

### 修改监控周期

在 `sys_monitor.c` 中修改：

```c
#define MONITOR_PERIOD_MS       5000    /* 改为 10000 表示 10 秒 */
```

### 启用高级功能

在 `sys_monitor.h` 中启用：

```c
#define MONITOR_ENABLE_ADVANCED     1
```

启用后可以使用：

```c
/* 重置统计计数器 */
SysMonitor_ResetStats();

/* 打印任务详细执行时间 */
SysMonitor_PrintTaskTiming(&Protocol_Task_TCB);
```

### 修改监控任务优先级

```c
#define MONITOR_TASK_PRIO       20   /* 优先级越低越好，避免影响正常任务 */
```

## 常见问题

### 1. 编译错误：identifier "OS_TASK_STATE" is undefined

**原因**: 不同版本的 uC/OS-III 使用不同的类型名称

**解决**: 代码已修复，使用 `OS_STATE` 替代 `OS_TASK_STATE`

### 2. 编译错误：identifier "OSTaskListPtr" is undefined

**原因**: 任务列表指针在某些配置中不可用

**解决**: 代码已修复，移除了任务列表遍历功能，改为检查特定任务

### 3. 编译错误：struct "os_msg_pool" has no field "NbrMax"

**原因**: 不同版本的 uC/OS-III 结构体字段不同

**解决**: 代码已修复，使用 `NbrFree + NbrUsed` 计算总数

### 4. CPU 使用率显示为 0%

**原因**: 统计任务需要运行一段时间才能计算出准确的 CPU 使用率

**解决**: 等待几秒钟后再查看，确保 `OSStatTaskCPUUsageInit()` 已调用

### 5. 堆栈使用率为 0%

**原因**: 任务从未运行过，或堆栈检查未启用

**解决**: 
- 确保 `OS_CFG_STAT_TASK_STK_CHK_EN` 设置为 1
- 确保任务已经运行过

### 6. 监控任务本身占用太多 CPU

**原因**: 监控周期设置太短，或打印输出太频繁

**解决**: 
- 增加 `MONITOR_PERIOD_MS` 到 10000 或更高
- 减少打印内容

### 7. 编译错误：OSStatTaskCPUUsage 未定义

**原因**: 统计任务未启用

**解决**: 确保 `os_cfg.h` 中 `OS_CFG_STAT_TASK_EN` 设置为 1

## 性能优化建议

### 1. CPU 使用率过高

- 检查是否有任务陷入死循环
- 降低非关键任务的优先级
- 减少任务数量，合并相似功能

### 2. 堆栈使用率过高

- 增加任务栈大小
- 减少局部变量使用
- 避免在任务中调用递归函数

### 3. 中断禁用时间过长

- 缩短临界区代码
- 使用更高效的同步机制
- 考虑使用中断嵌套

### 4. 上下文切换过于频繁

- 增加任务延时时间
- 使用事件标志替代轮询
- 合并频繁切换的小任务
